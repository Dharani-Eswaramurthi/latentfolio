# Contributing

Contributions that improve accessibility, browser compatibility, documentation, performance, or maintainability are welcome.

1. Open an issue before proposing a substantial visual or architectural change.
2. Create a focused branch and preserve the fictional nature of the demo content.
3. Run `npm ci` and `npm run build` before opening a pull request.
4. Explain the behavior changed, verification performed, and any accessibility or theme impact.

Do not add personal data, unverifiable claims, secrets, tracking scripts, or copyrighted assets without a compatible license.
